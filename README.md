## Prototype Explanation

### Pages Created

The Campus Connect prototype contains three pages:

* Home
* About Campus Connect
* Contact Us

### Navigation

Users move between the three pages using the navigation links at the top of the website. The active page link is highlighted so users can easily identify the page they are currently viewing.

**Active Page Link:** [Paste your live Campus Connect website link here]

### Semantic HTML Used

Semantic HTML elements used include `<header>`, `<nav>`, `<main>`, `<section>`, `<form>`, and `<footer>`. These elements help organize the website content clearly.

### Form

The **Contact Us** page contains a form intended to collect the user's name, email address, and message or inquiry.

### Accessibility Decisions

* Images have descriptive **alt text** to help users using screen readers.
* Clear headings and navigation links make the website easier to understand and navigate.
