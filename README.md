# semantic-html
semantic html prototype for this assignment

## Prototype Explanation

### Pages Created

The Campus Connect prototype contains three pages:

* Home
* About Campus Connect
* Contact Us

### Navigation

Users move between the three pages using the navigation links at the top of the website. The active page link is highlighted so users can easily identify the page they are currently viewing.

**Active Page Link:** https://ahimbisevivianpearl-spec.github.io/semantic-html/

### Semantic HTML Used

Semantic HTML elements used include `<header>`, `<nav>`, `<main>`, `<section>`, `<form>`, and `<footer>`. These elements help organize the website content clearly.

### Form

The **Contact Us** page contains a form intended to collect the user's name, email address, and message or inquiry.

### Accessibility Decisions

* Images have descriptive **alt text** to help users using screen readers.
* Clear headings and navigation links make the website easier to understand and navigate.


## Responsive Testing

The website was tested on both mobile and desktop screen sizes.

- Mobile: Tested on a smartphone screen.
- Desktop: Tested on a laptop/desktop screen.
- Navigation: Checked that Home, About Campus Connect, and Contact Us links work correctly.
- Images: Checked that images resize without overflowing the screen.
- Contact form: Checked that the form fields and button fit correctly.
- Horizontal scrolling: Checked that no unwanted horizontal scrolling occurs.

### Problem Corrected

The navigation links were initially displayed differently on some pages. The navigation structure and CSS were corrected so that Home, About Campus Connect, and Contact Us are aligned consistently across all three pages.
